## 💭 처음 접근 방식

**접근 아이디어:** 
- 알파벳에 대해 범위를 적용하여 필터링하기

```cpp
#include <string>
#include <vector>
#include <iostream>

using namespace std;

bool solution(string s) {
    bool answer = true;
    
    if (s.size() !=4 && s.size() != 6)
    {
        answer = false;
        return answer;
    }
    
    else
    {
        for (auto c : s)
        {
            if (c >= 'A' && c <= 'z')
            {
                answer = false;
                return answer;
            }
            else continue;
        }
    }
    
    return answer;
}
```

**틀린 이유:**  
- 틀린건 아니지만 더 좋은 방법이 존재한다

## ✅ 올바른 풀이

**핵심 아이디어:** 
- char에 대해 isalpha() / isdigit() 을 이용해서 코드를 더 이쁘게 리팩터링 가능

```cpp
#include <string>
#include <vector>

using namespace std;

bool solution(string sentence) {
    int size = sentence.size();
    
    if (size !=4 && size != 6) 
        return false;
    
    for (auto ch : sentence)
        if ( !isdigit(ch) ) 
            return false;        

    return true;
}
```
