## 💭 처음 접근 방식

**접근 아이디어:** 
- 처음에는 unique()를 떠올렸으나, 정확한 사용법과, 동작 메커니즘을 몰라 포기
- 대신에 문제의 의도대로 stack을 사용해서 solve

```cpp
#include <vector>
#include <stack>
#include <algorithm>
using namespace std;

vector<int> solution(vector<int> arr) 
{
    vector<int> answer;
    stack<int> uniqueStack;
    
    for (auto num : arr)
    {
        if(uniqueStack.size() == 0) uniqueStack.push(num);
        if(uniqueStack.top() != num) uniqueStack.push(num);
    }
    
    int size = uniqueStack.size();
    for (int i = 0; i < size; i++)
    {
        answer.push_back(uniqueStack.top());
        uniqueStack.pop();
    }
    reverse(answer.begin(), answer.end());
    
    return answer;
}
```

**틀린 이유:**  
- 틀리지는 않았지만, unique()를 사용하면 쉽게 solve 가능

## ✅ 올바른 풀이

**핵심 아이디어:** 
- unique()를 사용하면 컨테이너의 연속된 중복을 제거해준다
	- reverse()와 같이 시작과 끝을 넣어주면 된다!

```cpp
#include <vector>
#include <algorithm>
std::vector<int> solution(std::vector<int> arr) 
{
    arr.erase(std::unique(arr.begin(), arr.end()),arr.end());
    std::vector<int> answer =  arr;
    return answer;
}
```

## 📌 다음에 기억할 것
- unique()의 경우 집합을 만들어주는 것이 아닌 연속된 값을 제거해준다
- 그러나 제거하고 찌꺼기를 push_back()한다, 다행히 unique의 반환값은 찌꺼기의 시작 반복자다
	- 이를 이용해 해당 로직이 완성된다
