## 💭 처음 접근 방식

**접근 아이디어:** 
- 정렬 이후 반복문을 돌며 0부터 9까지가 numbers에 있나 체크하기

```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

int solution(vector<int> numbers) {
    int answer = 0;
    
    sort(numbers.begin(), numbers.end(), greater<>());
    
    int i = 0;
    while(true)
    {
        if( numbers.back() != i) 
        {
            answer += i;
            i++;
        }
        else
        {
            numbers.pop_back();
            i++;
        }
        
        if (i == 10) break;
        
    }
    
    return answer;
}
```

**틀린 이유:**  
- 틀리진 않았으나, 다른 사람의 풀이에 더 좋은 방법이 존재 (역으로 접근하기)

## ✅ 올바른 풀이

**핵심 아이디어:** 
- 거꾸로 0~9의 합인 45에서, number의 숫자를 빼는 식으로 접근하기

```cpp
#include <vector>

using namespace std;

int solution(vector<int> numbers) {
    int answer = 45;
    
    for (auto num : numbers)
        answer -= num;
    
    return answer;
}
```
