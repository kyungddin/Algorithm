## 💭 처음 접근 방식

**접근 아이디어:** 
- 대문자, 소문자, 공백의 세 가지 케이스에 대해서 알고리즘을 설계
- 알파벳의 경우에는 Circular Shift를 해야 한다

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

string solution(string s, int n) {
    string answer = "";
    
        for (auto c : s)
        {
            if (c >= 'a' && c<= 'z')
            {
                c = toupper(c);
                c = c + n;
                if (c > 'Z') c = c - 26;
                c = tolower(c);
                
                answer += c;
            }

            else if (c >= 'A' && c <= 'Z')
            {
                c = c + n;
                if (c > 'Z') c = c - 26;

                answer += c;
            }
            else if (c = ' ')
            {
                answer += " ";
            }
        }
    
    return answer;
}
```

**틀린 이유:**  
- 알파벳 개수가 26인데 잘못 계산

## ✅ 올바른 풀이

**핵심 아이디어:** 
- 틀린 건 아닌데 리팩터링 하기
- 소문자의 경우에는 char 오버플로우 때문에 대문자로 변환하는 과정을 거쳤는데, 이를 모듈러로 해결 가능

```cpp
#include <string>
#include <vector>

using namespace std;

#define ALPHA_SIZE 26

string solution(string sentence, int num) {
    string answer = "";
    
        for (auto ch : sentence)
        {
            if (ch >= 'a' && ch <= 'z')
            {
                ch = (char)((ch - 'a' + num) % ALPHA_SIZE + 'a');
            }
            else if (ch >= 'A' && ch <= 'Z')
            {
                ch = (char)((ch - 'A' + num) % ALPHA_SIZE + 'A');
            }           
            answer += ch;
        }
    
    return answer;
}
```
