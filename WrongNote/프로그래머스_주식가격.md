## 💭 처음 접근 방식

**접근 아이디어:** 
- 스택이나 큐를 활용한 풀이가 도저히 떠오르지 않아, 이중 반복문으로 풀었다

```cpp
#include <vector>

using namespace std;

vector<int> solution(vector<int> prices) {
    vector<int> answer;
    
    int count = 0;
    for (int i = 0; i <prices.size() - 1; i++)
    {
        for (int j = i + 1 ; j < prices.size(); j++)
        {
            count++; 
            if (prices[j] < prices[i]) break;
        }
        
        answer.push_back(count);
        count = 0;
    }
    answer.push_back(0);
    
    return answer;
}
```

**틀린 이유:**  
- 테스트 케이스가 널널하기도 하고, 평균 복잡도를 고려하면 통과가 가능했지만, 최악의 경우에는 O(n^2)의 복잡도로 터질 코드다
