## 💭 처음 접근 방식

**접근 아이디어:** 
- Step 1: 알파벳 기호에 대해 사전 채우기
- Step 2: 예외처리 (오버플로우에 대해 break)
- Step 3: 메인로직
	- 사전에 있으면 cache에 값 넣고 길이 늘리기
	- 사전에 없으면 cache 값 출력하고 사전에 subStr 추가하기

```cpp
#include <string>
#include <vector>
#include <unordered_map>

using namespace std;

vector<int> solution(string msg) {
    vector<int> answer;
    unordered_map<string, int> dictionary;
    
    // Step 1: Init
    int num = 1;
    for(char ch = 'A'; ch <= 'Z'; ch++)
    {
        string alpha(1, ch);
        dictionary[alpha] = num++;
    }
    
    // Step 2: Main Logic
    string cache = "";
    string word = "";
    int length = 1;
    int idx = 0;
    int msgEnd = msg.size() + 1;
    
    while(idx + length != msgEnd)
    {
        word = msg.substr(idx, length);
        
        if (dictionary.count(word))
        {
            cache = word;
            length++;
        }
        else
        {
            answer.push_back(dictionary[cache]);
            dictionary[word] = num++;
            idx = (idx + length - 1);
            length = 1;
        }
    }
    
    // Step 3: Last Word
    answer.push_back(dictionary[word]);
    
    return answer;
}
```

**틀린 이유:**  
- 애매한 변수명과 무작정 코드를 작성하는 것들이 겹쳐서, 구현 자체가 힘들었던 것 같다 (아이디어 자체는 괜찮았던 거 같음)

## ✅ 올바른 풀이

**핵심 아이디어:** 
- 2패스가 아닌 단일 패스로 처리 
- cache에 사전에 존재하는 가장 긴 문자열을 유지 
- 사전에 없는 단어가 나오면 cache를 출력하고, 해당 단어를 사전에 추가 
- 루프 종료 시점의 word는 항상 사전에 존재함 
	- 없으면 루프 안에서 처리되고 넘어갔을 것이므로

```cpp
#include <string>
#include <vector>
#include <unordered_map>

using namespace std;

vector<int> solution(string msg) {
    vector<int> answer;
    unordered_map<string, int> dictionary;
    
    // Step 1: Init
    int num = 1;
    for(char ch = 'A'; ch <= 'Z'; ch++)
    {
        string alpha(1, ch);
        dictionary[alpha] = num++;
    }
    
    // Step 2: Main Logic
    string cache = "";
    string word = "";
    int length = 1;
    int idx = 0;
    int end = msg.size() + 1;
    
    while(idx + length != end)
    {
        word = msg.substr(idx, length);
        
        if (dictionary[word] != 0)
        {
            cache = word;
            length++;
        }
        else
        {
            answer.push_back(dictionary[cache]);
            dictionary[word] = num++;
            
            cache = "";
            word = "";
            idx = (idx + length - 1);
            length = 1;
        }
    }
    
    // Step 3: Last Word
    if (dictionary[word] != 0)
        answer.push_back(dictionary[word]);   
    else
        answer.push_back(num);
    
    return answer;
}
```

## 📌 다음에 기억할 것
- unordered_map에 값이 있는지 판단할 때는 단순히 `if (hashMap.count())` 이런식으로 하는게 좋다
- 로직을 정확하게 파악하면 불필요한 else 문을 제거할 수 있다
